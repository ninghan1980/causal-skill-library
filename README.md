# 因果知识库 (Causal Knowledge Library)

> 把「世界如何运转」编码成机器可推理的结构 —— 24,565 条「原因→结果」因果原子,构成一张带反馈环的因果网络。

## 这是什么

不是普通的知识文档库,而是一个**可推理的外部世界模型**:

每条因果原子是带元数据的结构化记录,而非一行文字:

```json
{
  "cause": "央行降低存款准备金率",
  "effect": "银行可贷资金增加",
  "confidence": 0.9,
  "mechanism": "货币政策工具",
  "condition": "一般成立",
  "domain": "经济学",
  "evidence_type": "stated_mechanism"
}
```

每条原子都标注:置信度 / 传导机制 / 成立条件 / 领域 / 证据类型(实证 vs 理论推断)/ 反例 —— **诚实标注,可溯源、可校准**。

## 规模与拓扑

| 指标 | 数值 |
|---|---|
| 因果原子 | **24,565** 条 |
| 领域覆盖 | **115** 个(经济/金融/医学/免疫/军事/地缘政治/物理/天文…) |
| 环率(反馈环占比) | **23.7%**(重构前 0.04%,592×) |
| 最大强连通分量 | **1,324** 节点(参照:果蝇脑 1,188) |
| 互惠率(A→B 与 B→A 共存) | **31.99%** |

### 果蝇脑化重构(2026-09)

按生物神经环路设计原则重构拓扑:

1. **反馈边生成** — 对每条 A→B,按领域规则/关键词规则判定是否应有 B→A
2. **富俱乐部互联** — top 1% 高连接节点(178个)互联 + 跨域枢纽连接
3. **两轮迭代** — 推环率到目标

意义:结构从「纯前馈树」变为「大规模递归网络」——1,324 节点的 SCC 意味着信息可以循环,**系统可以"思考自己的思考"**。

## 能做什么

### 六个命令(统一入口 skill_server)

| 命令 | 功能 | 实测示例 |
|---|---|---|
| `ask <问题>` | 一键问答(检索+推理+建议) | "央行降准对实体经济影响" → 因果链+关联原子+行动建议 |
| `reason <前提> [目标]` | 多跳因果链推理 | 降准→可贷资金↑→流动性充裕→融资成本↓→投资扩张→就业↑(5跳) |
| `risk <原因>` | 风险分级评估 | 美联储加息 → 风险[极高] 0.765 → 美债收益率↑→全球融资成本↑ |
| `predict <事件>` | 情景预测 | 概率排序 + 方向判断 |
| `sim <模型> <参数>` | 物理引擎模拟 | 53 个模型:地震波/台风/溃口/金融 |
| `status` | 库状态 | 24,565 条 / 98 领域 / 244 技能注册 |

### 检索增强生成 (RAG for LLM)

因果库可作为 LLM 的**外置因果记忆**:

```
查询 → bigram 倒排召回(IDF+覆盖度归一) → 词嵌入精排(NLEmbedding 300维)
     → 实体词命中奖励 → 融合排序 → 原子注入 prompt → 模型推理
```

实测对比(同核模型):

| | 裸模型 | 检索增强 |
|---|---|---|
| 元首会晤影响 | 泛谈"降低尾部风险" | 引用原子[1] 0.75 + 成立条件 + 重复博弈机制 |
| 对台军售风险 | 威慑论 vs 升级论 | 引军工复合体原子 + 推出自我强化回路 |

**协议**:模型被要求 ①引用原子编号+置信度 ②注明成立条件 ③库外知识标注"(库外)"——推理可溯源、可校准。实测中模型会主动做**原子可用性筛查**(识别反向边/低置信边),协议生效。

## 诚实边界

- **理论推断原子占多数**(evidence_type=theoretical_inference),confidence 是标注值,不是统计估计
- 富俱乐部跨域边存在噪声(低置信度弱连接),库层质量分层进行中
- 检索为词面(bigram)+词级嵌入,深度语义推理依赖下游 LLM
- 领域命名存在历史混乱(如"物理学/间接因果"),清洗进行中

## 一条事实订正

## 关于「可推理」的范围

| 层 | 条数 | 可推理 |
|---|---|---|

# 附：动力学引擎（2026-09-26 追加）

> **本节为追加内容，未改动以上任何原有表述。**

库原本是静态的图。本节给它装上**状态、更新规则、反馈**，并给出**可量测的「活不活」判据**。

## 用法

```bash
apt install python3-numpy python3-scipy
python3 tools/classify_tiers.py          # 先分级，导出干净子集（只需跑一次）
echo '{"graph":"clean","start":"全球变暖","compare":"海平面上升"}' \
  | python3 alive/causal_dynamics.py
```

详见 [`alive/README.md`](alive/README.md)。

## 判据（三条全满足才算「计算」）

| | 判据 | 阈值 |
|---|---|---|
| **L1** | 非平凡：稳态不是常数 | 标准差 > 1e-4 |
| **L2** | 输入依赖：换起点稳态要变 | 余弦 < 0.9 |
| **L3** | 有选择性：不是全图都亮 | 活跃占比 < 5% |

只满足 L1 = 震荡；L1+L2 = 回声；三条全满足 = 计算。

## 实测结果

**`clean` 图（11,602 条干净主张）→ 判定 = 计算**

```
起点「全球变暖」
  粮价上涨 0.458   粮食安全威胁 0.152   农业减产 0.057
  海岸线后退 0.043  沿海地区淹没风险 0.043  沿海城市淹没风险 0.038
L2 与「海平面上升」的余弦 = 0.173  →  输入依赖 True
```

**`measured` 图（1,059,501 条连接组）→ 判定 = 无选择性**

```
起点「Mi1」
  L1 0.144   L2 0.141   R1-R6 0.125   L5 0.106   L4 0.085
L2 与「T4a」的余弦 = 0.981  →  输入依赖 False
```

**连接组在细胞型层级太稠密递归**：40 步扩散后从哪出发都一样。
**结构是真的，但选择性不够** —— 「边是真的」并不能保证「图能计算」。

## 结论

**动力学测的是结构的选择性，不是边的真伪。**

- `clean` 图通过判据 **≠ 主张是对的**。它的边依旧 100% `direction_source=assumed`。
  一个自洽但错误的图，一样能通过 L1/L2/L3。
- 引擎传播的是**结构**，不是**效应**。`measured` 层是 structural connectivity。
- **尚无去重**：库里 383 组近义概念（「电阻」有 8 个变体）会分掉激活能量。

## 开发中修掉的两个 bug（留档）

**bug-1 方向写反**：用 `Mn.T@a` 而非 `Mn@a` → 从「全球变暖」走到了它的**原因**。
靠**经验 sanity check** 发现（看激活集内容合不合理），不是读代码。

**bug-2 绝对阈值 —— 判据自己会说谎**：阈值 `θ=0.02` 是绝对量，
起点出边多时每条分不到 θ 全被杀 → 传播断掉、只剩起点，
**而三条判据仍全报 True、输出「判定=计算」**。
已改为相对阈值 `θ*max`，并新增 `degenerate` 检查：
**激活集只剩起点时，判据一律不算数。**
