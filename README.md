## 重构方法

按果蝇脑设计原则重构：
1. **反馈边生成**：对每条 A→B，按领域/关键词判定是否应有 B→A（反向置信度 = 正向 × 0.75）
2. **富俱乐部**：top 1% 高连接节点（178个）互联 + 跨域枢纽连接
3. **两轮迭代**：第一轮 0.04→12.83%，第二轮 12.83→23.70%
