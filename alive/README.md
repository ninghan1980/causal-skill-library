# 动力学引擎（Dynamics Engine）

给这个库装上**状态、更新规则、反馈**，并给出**可量测的「活不活」判据** ——
不是动画，是判据。

## 用法

```bash
# 依赖
apt install python3-numpy python3-scipy     # 或 pip install numpy scipy

# 先分级，导出干净子集（只需跑一次）
python3 tools/classify_tiers.py

# 传播激活
echo '{"graph":"clean","start":"全球变暖","compare":"海平面上升"}' \
  | python3 alive/causal_dynamics.py
```

## 参数

| 键 | 说明 | 默认 |
|---|---|---|
| `graph` | `clean` / `full` / `measured` / `fafb` | `clean` |
| `start` | 起点标签，可模糊匹配；省略则取出度最高节点 | — |
| `compare` | 第二个起点，用于测 L2 | — |
| `mode` | `nonlinear`（相对阈值 + 侧抑制）/ `linear` | `nonlinear` |
| `steps` / `decay` / `top_k` | 步数 / 衰减 / 返回条数 | 40 / 0.2 / 10 |

## 活性判据

| | 判据 | 阈值 |
|---|---|---|
| **L1** | 非平凡：稳态不是常数 | 标准差 > 1e-4 |
| **L2** | 输入依赖：换起点稳态要变 | 余弦相似度 < 0.9 |
| **L3** | 有选择性：不是全图都亮 | 活跃节点占比 < 5% |

只满足 L1 = **震荡**；L1+L2 = **回声**；三条全满足 = **计算**。

## 实测结果

### `clean` 图（11,602 条干净主张）→ **计算**

```
起点「全球变暖」
  粮价上涨 0.458   粮食安全威胁 0.152   农业减产 0.057
  海岸线后退 0.043  沿海地区淹没风险 0.043  沿海城市淹没风险 0.038
L2 与「海平面上升」的余弦 = 0.173  →  输入依赖 True
```

### `measured` 图（1,059,501 条连接组）→ **无选择性**

```
起点「Mi1」
  L1 0.144   L2 0.141   R1-R6 0.125   L5 0.106   L4 0.085
L2 与「T4a」的余弦 = 0.981  →  输入依赖 False
```

**连接组在细胞型层级太稠密递归**：40 步扩散后从哪出发都一样。
结构是真的，但**选择性不够** —— 这说明「边是真的」并不能保证「图能计算」。

## 开发中修掉的两个 bug（留档）

### bug-1 方向写反

```python
a = Mn.T @ a     # ✗ 往【上游】流
a = Mn   @ a     # ✓ 正向：cause → effect
```

症状：从「全球变暖」出发，激活的是**化石燃料燃烧、二氧化碳增加** ——
那是它的**原因**，不是后果。

**靠经验 sanity check 发现（看激活集内容合不合理），不是读代码。**

### bug-2 绝对阈值 —— **判据自己会说谎**

阈值 `θ=0.02` 是**绝对量**。起点出边多时每条分不到 θ，全被杀死 →
传播完全断掉、**只剩起点**，**而三条判据仍全报 True、输出「判定=计算」**。

已改为**相对阈值** `θ*max`，并新增 `degenerate` 检查：
**激活集只剩起点时，判据一律不算数。**

> 教训：三条判据全满足时，先看激活集是不是只剩起点。

## 边界

- 传播的是**结构**，不是**效应**。`measured` 图是 structural connectivity，
  不是 effective connectivity —— 知道突触在哪，不知道信号传不传、多强。
- `clean` 图过判据 **≠ 主张是对的**。它的边依旧 100% `direction_source=assumed`。
  **动力学测的是结构的选择性，不是边的真伪。**
- 尚无去重：库里 383 组近义概念（如「电阻」有 8 个变体）会分掉激活能量。
